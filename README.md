# Takip etmeyenler

Instagram'da seni geri takip etmeyenleri bulan tarayıcı konsolu scripti. Profil fotoğrafları, onay/gizli rozetleri, tek tek takibi bırak ve listeyi kopyala özellikleri var.

**Site:** https://okansarioglu.github.io/takip-etmeyenler/

Kullanım: instagram.com'da giriş yap → sağ tık → İncele → Console → gerekirse `allow pasting` yaz → `script.js` içeriğini yapıştır → Enter.

> Resmi değildir, sık çalıştırma; risk kullanıcıya aittir.
